# BCG · AI 거버넌스 정책과 Agent 통제의 간극 (편집형)

## 원문 요지 (직접 작성, 3문장)
BCG는 26개 주요 은행을 대상으로 AI 채택 수준과 위험관리 성숙도를 조사했다. 은행의 AI 정책 수립은 상당히 진전됐지만 Agent 전용 통제·모니터링은 성숙하지 않았다. AI 도입과 통제의 운영화는 서로 다른 실행 역량으로 평가해야 한다.

**So what — AI Agent의 배포를 확대할 때 정책 보유 여부가 아니라 실제 운영 중인 통제체계 성숙도를 별도 KPI로 관리해야 한다.**

### 비즈니스 맥락 → 데이터 → 판단
- 맥락: 은행의 Agent 자율성 증가에 따른 관리 필요
- 지표/단위: 조사 은행 중 각 조건을 충족한 비율(%). 2026년 조사, 주요 은행 26개, 설문 문항별 유효 분모는 미공개
- 값: AI 정책 보유 77%, 일부 Agent 운영 허용 73%, 포괄적 Agent 통제 보유 8% (`reported`)
- 비교: 서로 **다른 문항**의 주변비율이며 배타적 단계가 아니다. 개인 은행 단위의 이행 전환율로 해석 금지
- 판단: 정책·배포와 통제 운영화의 높은 수준 차이는 과제로 볼 수 있으나 특정 은행이 통제가 없는지 확인되지 않음

### 디자인 근거
- 인사이트 유형: capability maturity contrast (서로 다른 조건의 보급도 비교)
- x: 0–100% 비율, 0 기준, 20% tick; y: 거버넌스 활동; 색: 통제 항목 강조; 막대 길이: 비율; 정렬: 값 내림차순
- 제목은 질문을 직접 전달하며 직접값 레이블과 출처를 사용. 범례 불필요, 간격과 여백은 테마 설정
- 공식 Exhibit는 AI 채택·위험 성숙도를 교차한 정성 분류 시각화; 이 그림은 **원본 재현이 아닌 본문 수치 편집형 차트**임

### 공개 출처·표본·계산
- 원문: https://www.bcg.com/publications/2026/ai-governance-banking-benchmark (2026-11-13)
- BCG AI Safety and Governance in Banking 2026, 26개 주요 은행; 정확한 응답 방식/문항별 실측 원자료·가중치 미공개
- 값은 원문 본문을 그대로 입력 (`reported`). 숫자별 계산·합성 없음. 소수점 반올림으로 26개 기준 정수 환산 금지

### 단계별 재사용 data_recipe
1. 은행/조직별 정책·통제 조건을 정의하고 질문별 대상 분모를 보존한다.
2. `condition`, `value`, `period`, `provenance`, `denominator`로 정형화한다.
3. 값 누락·문항별 대상 차이를 검증한 뒤 비율을 계산한다.
4. 설정의 `CONTEXT`와 `THEME`을 바꾸고 같은 `render()`로 렌더링한다.

### 메시지 성립 조건·반례·한계
- 서로 다른 조건의 비율이므로 77% 중 8%가 통제를 갖췄다는 계산이나 퍼널 전환율을 산출할 수 없다.
- 통제를 실제로 보유한 8%가 도입을 허용한 73%의 부분집합인지 원자료로 확인 불가.
- 표본 26개 은행에 국한되며 전체 금융기관 모집단 일반화와 인과적 효과 주장은 불가.
- 공식 원본 그림의 배치를 직접 시각 검증하지 못했으므로 자체 충실도 `null`, `unverified`.

### 사용법
`pip install -r requirements.txt` 후 `python chart.py --data data.csv --config config.json --theme source --output source.png`; 중립 버전은 `--theme neutral`.
